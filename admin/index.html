Hana Baraka — Website-Backend

Werke, Bilder und Platzierung pflegen — ohne Excel/Google Sheet.

Zugang

Zum Speichern braucht diese Seite einen persönlichen GitHub-Zugriffstoken (nur einmal einrichten, bleibt danach in diesem Browser gespeichert). Wie bekomme ich einen Token?

  1. Auf github.com einloggen → oben rechts Profilbild → Settings
  2. Ganz unten links → Developer settings → Personal access tokens → Fine-grained tokens
  3. Generate new token → Namen vergeben, Ablaufdatum setzen
  4. Bei Repository access → Only select repositories → genau dieses Hana-Repo auswählen
  5. Bei Permissions → Repository permissions → Contents auf Read and write stellen
  6. Token erzeugen, kopieren (wird nur einmal angezeigt!) und unten einfügen

Werke

Ein Werk = ein Titel/Preis/Story-Eintrag. Bilder dazu kommen im Tab „Bilder & Medien“ — jedes Werk kann mehrere Bilder haben.

Neues Bild hochladen

Das Bild wird automatisch verkleinert und komprimiert (wie alle bisherigen Bilder der Seite), danach erscheint es als neue Zeile unten in der Tabelle — dort trägst du ein, zu welchem Werk es gehört und wo es erscheinen soll.

Medien

„home/portfolio/shop“ bestimmen, wo ein Bild als eigene Kachel auftaucht. „role“ = cover (Hauptbild im Popup) oder detail (weitere Ansicht). Bei Videos: type=video und die YouTube-Video-ID bei video_id eintragen.

Seiten-Texte

Texte, die fest auf der Seite stehen (Workshop-Abschnitt, Contact-Abschnitt, Navigation, Instagram) — unabhängig von den einzelnen Werken oben. Änderungen hier wirken sich auf der Live-Seite aus, sobald sie neu geladen wird.
